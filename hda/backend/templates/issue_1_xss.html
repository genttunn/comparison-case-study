<img src=x onerror="document.getElementById('attacker-panel').innerHTML='CAPTURED: ' + document.querySelector('.secret-notes-value').innerText">
Why the HDA is structurally safe:

Jinja2 auto-escapes all template variables by default. {{ '{{ comment.body }}' }} outputs &lt;img src=x...&gt; — the browser renders it as visible text, never as HTML. This is not an explicit sanitization call; it is how the template engine works. There is no way for user-supplied content to reach the DOM as raw HTML unless the developer deliberately uses the | safe filter, which this app does not.
