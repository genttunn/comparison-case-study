# Literature review

Raw data of the systematic literature review in Chapter 4 of the thesis. The quality assessment of the 144 screened studies was graded by Claude in three runs on 5–6 May 2026 and entered into Parsifal.

| File | Contents |
|---|---|
| `result1.csv` | Run 1 scores: titles only, five criteria. Compiled from the grades in chat C |
| `result2.csv` | Run 2 scores: titles only, six criteria. Parsifal export |
| `result3.csv` | Run 3 scores: titles, keywords and abstracts, six criteria. Parsifal export, used for the selection |
| `result3-with-availability.ods` | Run 3 scores with a column for whether the paper could be downloaded |
| `result3-ranked.txt`, `result3-rejected.txt`, `result3-collections.txt` | Run 3 answers per criterion, as produced by Claude |
| `parsifal-grade-input-script.js` | Browser script that entered the Run 3 answers into Parsifal |
| `article-ids.md` | Parsifal article IDs of the 144 studies |
| `articles-information.csv` | Titles, authors, keywords and abstracts of the 144 studies, the input of Run 3 |
| `chats/` | Exports of the Claude chats: A (page summary), B (Run 1), C (Run 1 grades ranked), D (Run 2), E (Run 3) |

The `Number` column in the result files is the study's number in the Parsifal export, the same in all three runs.
